# 彷徨 — SAMAYOI

**▶ 遊ぶ： https://orihami.github.io/samayoi/**

ブラウザで動く3Dホラーゲーム。迷宮でお札を5枚集め、出口から脱出する。アレに見つかったら走れ。逃げきれないなら、ロッカーに隠れろ。

- `index.html` 1ファイルだけで動く（three.js 同梱、外部読み込みなし）
- ヘッドホン推奨／強い点滅と大きな音あり

## 操作
| PC | スマホ | |
|---|---|---|
| WASD / マウス | 左ドラッグ / 右ドラッグ | 移動 / 視点 |
| Shift | 走 | 走る |
| F | 灯 | 懐中電灯 |
| E | 隠 / 出 | ロッカーに入る・出る |
| Space | 息 | 息を止める |
| Q・右クリック | 覗 | 覗く |

## ビルド
`src/` で `npm install && npm run build` → ルートの `index.html` が更新される。
